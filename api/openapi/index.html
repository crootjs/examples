Dokumentasi API dengan openapi.js

Halaman ini dibuat dari berkas OpenAPI (.yaml) dengan openapi.js, pengganti Swagger UI yang ditulis sendiri. Setiap operasi punya kode CrootJS untuk memanggilnya dan tombol untuk mencobanya.

Sumber: catatan.yaml. Pakai sendiri: salin index.html, index.js, dan berkas spesifikasi Anda ke repo GitHub Pages.
