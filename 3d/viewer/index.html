Penampil Model 3D + CrootJS

Model glTF/GLB ditampilkan langsung di browser dengan WebGL, tanpa Three.js atau library lain.

Putar, zoom, lalu klik sebuah bagian

Geser untuk memutar, roda mouse atau pinch untuk zoom, klik kanan + geser (atau dua jari) untuk menggeser pandangan, klik ganda untuk memusatkan. Buka file .glb sendiri untuk mencoba model lain.
