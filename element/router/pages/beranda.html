Beranda

Dashboard satu halaman dengan router.js. Isi halaman berganti tanpa memuat ulang, alamatnya tetap bisa di-bookmark, dan tombol back browser berfungsi.

  • Daftar mahasiswa memuat data contoh dari file JSON dan bisa dicari (query ?q=).
  • Klik satu nama untuk halaman detail dengan parameter, misalnya #/mahasiswa/2301001.
  • Menu Jadwal sengaja belum dibuat, jadi menampilkan halaman tidak ditemukan.

Halaman ini sendiri adalah potongan HTML (pages/beranda.html) yang dimuat router ke dalam <main>. Sesudah pindah halaman, fokus keyboard pindah ke judul dan judulnya diumumkan ke pembaca layar.
