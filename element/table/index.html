Tabel Data + CrootJS

table.js: urut per kolom, cari, dan halaman untuk <table> biasa, tanpa jQuery DataTables. Datanya data contoh dari data.json yang dimuat dengan getJSON. Klik judul kolom untuk mengurutkan.
