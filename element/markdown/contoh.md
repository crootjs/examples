# Contoh file Markdown

File ini dimuat dengan `getMarkdown("contoh.md")`, yang mengambil file lalu mengubahnya menjadi HTML.
Isinya hanya contoh.

## Langkah

1. Tulis catatan sebagai file `.md` di repo.
2. Muat dengan `getMarkdown`.
3. Pasang hasilnya dengan `setInner` dari `element.js`.

Lihat [dokumentasi markdown.js](https://croot.js.org/docs/markdown).
