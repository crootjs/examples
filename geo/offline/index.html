Peta Offline (PMTiles) + CrootJS

Peta dasar dari satu file PMTiles - tanpa server tile. Buka file dari perangkat sendiri, dan peta tetap jalan walau internet putus. Tile raster maupun vektor.

Contoh file, atau file Anda sendiri

Peta di bawah membaca data/toner.pmtiles (raster, dunia, zoom 0-3). Tombol vektor membuka peta kota Firenze (6,6 MB, zoom 0-15) dari repositori PMTiles, yang digambar di browser dan tetap tajam sampai zoom 19. Pilih file .pmtiles dari perangkat untuk membukanya tanpa jaringan.
