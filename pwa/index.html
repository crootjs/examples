    Cara mencoba mode offline
    1. Buka halaman ini sekali selagi online, lalu muat ulang (service worker sudah terpasang).
    2. Putuskan internet: mode pesawat, atau DevTools → Network → Offline.
    3. Muat ulang: halaman, tampilan, dan catatan tetap ada. Catatan baru juga bisa disimpan.
